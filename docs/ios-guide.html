DayROAD 아이폰 설치하기

무료 애플 ID 로 내 아이폰에 설치 · ValoROAD 와 같은 방법이에요 (처음 한 번 약 10분)
먼저 맥에서
1

맥 DayROAD 를 1.4.1 로

맥 맥 DayROAD › 설정 › iCloud 저장이 켜져 있고 초록 체크가 보이면 돼요. 아이폰은 이 파일(iCloud Drive › DayROAD)을 같이 써요.

2

파일 풀기

맥 받은 DayROAD-iPhone.zip 을 더블클릭해 풀고, 나온 DayROAD-iPhone 폴더를 문서 폴더에 옮겨 두세요. 7일마다 다시 쓰니 지우지 마세요.

3

Xcode 로 열기

맥 폴더 안의 DayROAD.xcodeproj (파란 아이콘)를 더블클릭해요. 애플 ID 는 ValoROAD 때 넣어 둔 것을 그대로 써요.

4

팀 고르기 — 두 곳

맥 왼쪽 맨 위 파란 DayROAD 클릭 › 가운데 TARGETS 에서 DayROAD 를 고르고 Signing & Capabilities › Team = 내 이름 (Personal Team). 그다음 DayROADWidget 도 똑같이 골라요.

5

설치 ▶

맥 아이폰을 케이블로 연결(또는 같은 와이파이)하고, Xcode 맨 위 가운데에서 내 아이폰을 고른 뒤 왼쪽 위 ▶ 를 눌러요. 1~3분 뒤 아이폰에 DayROAD 아이콘이 생겨요.

6

개발자 신뢰ValoROAD 때 했으면 건너뛰기

아이폰 “신뢰하지 않는 개발자” 창이 뜨면 설정 › 일반 › VPN 및 기기 관리 › 내 애플 ID › 신뢰를 누르고 앱을 다시 열어요.

아이폰에서
7

DayROAD 폴더 고르기

아이폰 앱의 DayROAD 폴더 고르기 › ‘파일’ 창에서 iCloud Drive › DayROAD 폴더를 누르고 오른쪽 위 열기. 맥의 할 일이 그대로 들어와요. 알림 · 캘린더는 허용.

8

위젯 올리기

아이폰 홈 화면 빈 곳을 길게 누르기 › 왼쪽 위 편집 › 위젯 추가 › DayROAD › 작게 · 중간 · 크게 중에서 골라요. 위젯의 네모를 누르면 바로 끝내져요.

7일마다
▶
사용 기간이 끝난 뒤, 아이폰을 맥에 연결하고 Xcode 에서 ▶ 한 번

설정 화면의 남은 사용 기간 막대에 남은 날이 보이고, 끝나기 하루 전에 알림이 와요. 끝나기 전에 ▶ 를 누르면 끝나는 날이 그대로라서, 끝난 뒤에 눌러야 새로 7일이 시작돼요. 할 일은 iCloud 에 있어서 그대로예요.

이럴 땐
  • 4번에서 App Groups 오류가 뜨면: 무료 애플 ID 가 위젯용 공간을 못 만드는 경우예요. Xcode 맨 위 가운데 왼쪽(▶ 옆)의 DayROAD 를 눌러 DayROAD-NoWidget 으로 바꾸고, TARGETS 의 DayROAD-NoWidget 에서 팀을 고른 뒤 ▶ — 위젯만 빠지고 나머지는 똑같아요.
  • 4번에서 “Failed to register bundle identifier” 가 뜨면: 바로 위 Bundle Identifier 끝에 숫자를 붙여(예: …iphone2) 바꿔요. 위젯은 그 뒤에 .widget 을 그대로 붙여요.
  • 무료 애플 ID 는 아이폰에 앱 3개까지 설치할 수 있어요 (지금 ValoROAD · DayROAD = 2개).
  • 위젯에서 끝낸 것은 앱을 한 번 열면 맥에도 가요. 맥과 아이폰은 앱을 보고 있는 동안 6초마다 맞춰요.
  • 앱이 이상하면 설정 › 진단 정보 보기 › 보내기 를 눌러 그대로 보내 주세요.

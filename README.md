# DayROAD

**[⬇️ 앱 받기 (맥)](https://github.com/NeverthelessD/DayROAD/raw/main/download/DayROAD.zip)** — 풀어서 `DayROAD.app` 을 응용 프로그램 폴더로 옮기면 끝. 함께 든 사용 가이드 이미지를 봐 주세요.

오늘 할 일과 이번 주 할 일을 한 곳에서 관리하는 맥 앱 (Apple Silicon · macOS 14 이상).

- 오늘 · 이번 주 · 마감 다가옴 · 반복하는 일 · 언젠가 · 끝낸 일 · 분류
- 할 일마다 언제까지(마감) · 알림 · 반복 · 어디까지 했는지(진행 % + 기록)
- 못 끝낸 일은 다음 날로 자동으로 넘어와요
- 바탕화면 위젯 (작게 · 중간 · 크게, 눌러서 바로 끝내기)
- 맥에 연결된 iCloud · Google 캘린더 일정 보기 · 할 일을 캘린더에 넣기 · 아이폰 '미리 알림'과 맞추기
